# 装修排版神器（按 GB 50327-2001 12.3.1 重做排砖）

本机离线工具。地砖、墙砖、吊顶、家具按 **GB 55038-2025、GB 50210-2018、GB 50209-2010、GB 50327-2001** 先计算再校核。现场无法判定的空鼓、COF 试验不再标成“已符合”。

支持 **CAD（DXF）**、**PDF**、**语言描述**。

## 相对上一版改了什么

上一版校核了净高/防滑/吊杆几何，但排砖仍两边同时切边，门口不是整砖，门洞直接删砖，还把 **非整砖 ≥1/3** 标成“工艺不是国标”。GB 50327-2001 **12.3.1 原文就是条文**：

> 铺贴前应进行放线定位和排砖，非整砖应排放在次要部位或阴角处。每面墙不宜有两列非整砖，非整砖宽度不宜小于整砖的 1/3。突出物处应整砖套割吻合，不得用非整砖拼凑。阳角宜 45° 对接。

这一版按条文排：

- **地砖**：开间分中（两侧阴角对称收头）；进深从门口第一皮整砖，破活放对墙阴角；卫生间地漏落到整砖中心套割；图面画十字控制线（14.3.1）
- **墙砖**：水平方向一列非整砖放阴角；门窗洞口整砖套割，不用碎砖拼凑；立面标阳角条；卫生间另标淋浴防水 ≥2.00m、洗面器 ≥1.20m、泛水 ≥0.25m、地面防水上翻 ≥100mm（6.3.3）
- **吊顶**：主龙骨沿短跨；吊杆距端部 ≤300mm；吊点间距 &lt;1.2m；次龙骨 ≤600mm（潮湿 300～400mm）；短跨 2‰ 起拱；**边龙骨沿墙固定（8.3.1-6）**；灯位附骨；层高不足时改局部吊顶
- **家具/空间**：卧室 ≥5㎡ / 短边 ≥1.80m；厨房 ≥3.5㎡；三件套卫生间 ≥2.5㎡；过道 1.10 / 1.00 / 0.90m；门净宽按新建/既有分别校核。新建另检层高 ≥3.00m

默认按 **既有住宅装修**。新建请在界面选「新建住宅」。

不能替代施工图会审和现场放线。规范正文以正式文本为准。
