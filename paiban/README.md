# 装修排版神器（按现行国标重做）

本机离线工具。地砖、墙砖、吊顶、家具按 **GB 55038-2025、GB 50210-2018、GB 50209-2010、GB 50327-2001** 先计算再校核。空鼓、COF 试验等现场项目不再标成“已符合”。

支持 **CAD（DXF）**、**PDF**、**语言描述**。

## 这一版相对旧排版改了什么

旧版（含只按 12.3.1 字面改过的那一版）仍有这些问题：门永远当在南墙、墙砖仍可能两列收头、工字/人字是假的、强化地板没有 14.3.3 错缝、吊杆长度写死 0.20m 所以 **GB 50210-2018 7.1.11 反支撑永远不触发**、石膏板长边未垂直次龙骨、厨房不算防水房间、CAD 读不出门。

这一版按条文做：

- **地砖**：以实际门所在墙为 y=0 起铺，进口第一皮整砖，破活放对墙阴角；十字控制线对门中；卫生间地漏落到整砖中心套割，门口 ≤15mm 斜坡（55038 4.1.12）
- **墙砖**：每面只允许一列非整砖，且躲开门窗洞口；洞口整砖套割；阳角条；卫生间标淋浴防水 ≥2.00m / 洗面器 ≥1.20m / 泛水 ≥0.25m / 上翻 100mm
- **厨卫阳台**：**GB 50327 6.1.1** 必须做防水，地面防水上翻 ≥100mm（6.3.3）
- **强化地板**：**14.3.3** 相邻端头错缝 >300mm，不再套用瓷砖网格
- **工字缝**：错缝后边条仍 ≥整砖 1/3；人字铺明确按 45° 斜铺近似，不假装已排出人字缝
- **吊顶**：吊杆长度按空腔（高大空间做到规范净高），>1.5m 出反支撑；石膏板长边垂直次龙骨、端缝错开 ≥300mm；灯位/检修口附加龙骨；潮湿次龙骨 300～400mm
- **CAD**：0.6～2.2m 且贴墙的 LINE 识别为门，排砖从那面墙起铺

默认按 **既有住宅装修**。新建请在界面选「新建住宅」。
