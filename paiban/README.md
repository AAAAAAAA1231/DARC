# 装修排版神器（按现行国标重做）

本机离线工具。地砖、墙砖、吊顶、家具按 **GB 55038-2025、GB 50210-2018、GB 50209-2010、GB 50327-2001** 先计算再校核。现场无法判定的空鼓、COF 试验不再标成“已符合”。

支持 **CAD（DXF）**、**PDF**、**语言描述**。

## 相对上一版改了什么

上一版把国标编号盖在 `ok: True` 上，吊点按均匀网格生成，端部可以超过 300mm，卫生间也不强制防滑和找坡。这一版按条文排：

- **吊顶**：主龙骨沿短跨；吊杆距端部 ≤300mm；吊点间距 &lt;1.2m；次龙骨 ≤600mm（潮湿 300～400mm）；短跨 2‰ 起拱；灯位附骨；层高不足 2.80m 时满吊会低于卧起净高 2.60m，自动改为局部吊顶（局部面积 ≤1/3、局部净高 ≥2.20m）
- **地砖**：卫生间自动改选防滑砖（COF≥0.6 须检测报告）；布置地漏并按 1％ 坡向；门口高差按 ≤15mm 斜坡过渡。边砖 1/3 只作工艺建议
- **墙砖**：四面门洞套割；卫生间立面标出淋浴防水 ≥2.00m、洗面器 ≥1.20m、泛水 ≥0.25m
- **家具/空间**：卧室 ≥5㎡ / 短边 ≥1.80m；厨房 ≥3.5㎡；三件套卫生间 ≥2.5㎡；过道 1.10 / 1.00 / 0.90m；门净宽按新建/既有分别校核。新建另检层高 ≥3.00m

默认按 **既有住宅装修**。新建请在界面选「新建住宅」。

不能替代施工图会审和现场放线。规范正文以正式文本为准。
