# 工程质量（跟踪与纠偏）

本机质量工具。登记问题、跟踪整改闭环、写纠偏措施，导出 Excel 台账和整改通知单。

## 用法（只下载、双击）

1. 下载压缩包：https://github.com/AAAAAAAA1231/DARC/raw/cursor/zhiliang-qc-f8d9/zhiliang/dist/ZhiLiang.zip
2. 右键 → 解压到当前文件夹
3. 双击 `ZhiLiang.exe`
4. 若弹出「Windows 已保护你的电脑」：点 **更多信息** → **仍要运行**
5. 浏览器打开 http://127.0.0.1:8794 ；不要关黑窗口

浏览器若写「有病毒 / 已丢弃」：点 **保留 → 仍要保留**。请下 zip，不要直接下 exe。

数据在本机 `data/workspace.json`，不联网。

## 会做什么

- 质量问题台账：部位、专业、一般/较大/重大、责任人、期限
- 闭环：发现 → 整改 → 复查 → 闭合；超期标橙
- 纠偏：实测/允许/偏差，人机料法环，纠正措施 + 预防措施
- 通病模板（保护层、蜂窝、裂缝、防水、轴线、砌体、焊缝、管道、接地等）
- 质量巡检记录
- 导出 Excel：问题台账、整改通知单、纠偏记录、巡检、统计

## 不会做什么

- 不替代监理规范和检测报告
- 不存现场照片（可在备注写照片编号）
