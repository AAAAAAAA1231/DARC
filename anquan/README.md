# 工程安全（跟踪与纠偏）

本机安全工具。登记隐患、跟踪整改闭环、写纠偏措施，导出 Excel 台账和整改通知单。

## 用法（只下载、双击）

1. 下载压缩包：https://github.com/AAAAAAAA1231/DARC/raw/cursor/anquan-safety-f8d9/anquan/dist/AnQuan.zip
2. 右键 → 解压到当前文件夹
3. 双击 `AnQuan.exe`
4. 若弹出「Windows 已保护你的电脑」：点 **更多信息** → **仍要运行**
5. 浏览器打开 http://127.0.0.1:8795 ；不要关黑窗口

浏览器若写「有病毒 / 已丢弃」：点 **保留 → 仍要保留**。请下 zip，不要直接下 exe。

数据在本机 `data/workspace.json`，不联网。

## 会做什么

- 隐患台账：部位、类别、一般隐患/重大隐患、责任人、期限、是否停工
- 闭环：发现 → 整改 → 复查 → 闭合；超期标出
- 纠偏：现场情况/规范要求/偏差，人机料法环，纠正 + 预防
- 模板：临边洞口、脚手架、高支模、临电、消防、塔吊、基坑、有限空间、气瓶、占道施工等
- 安全巡查（日检/周检/危大巡视）
- 导出 Excel：隐患台账、整改通知单、纠偏记录、巡查、统计

## 不会做什么

- 不替代专项方案、危大论证和政府监管系统
- 不存现场照片（可在备注写照片编号）
