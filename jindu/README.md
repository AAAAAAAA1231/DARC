# 工程进度（横道图）

本机日常进度工具。维护 WBS、填报完成百分比和施工日志，导出 Excel / PNG 横道图。

## 用法（只下载、双击）

1. 下载压缩包：https://github.com/AAAAAAAA1231/DARC/raw/cursor/jindu-gantt-f8d9/jindu/dist/JinDu.zip
2. 右键压缩包 → 解压到当前文件夹
3. 双击 `JinDu.exe`
4. 若弹出「Windows 已保护你的电脑」：点左下角 **更多信息**，再点 **仍要运行**
5. 浏览器会打开 http://127.0.0.1:8793 ；不要关掉黑色窗口

浏览器下载时如果写「有病毒 / 已丢弃」：点下载栏的 **保留 → 仍要保留**。这是未签名软件的常见提示，不是文件里有木马。压缩包比直接下 `.exe` 更不容易被浏览器直接删掉。

数据保存在本机 `data/workspace.json`，不上传网络。

## 会做什么

- 房屋建筑 / 市政道路 / 装饰装修 / 钢结构厂房 进度模板，按合同开工日展开计划
- 完成-开始（FS）前置、滞后、总时差、关键线路
- 对照今天计算总进度、SPI、滞后项
- 施工日志（天气、人数、完成、问题、明日计划）
- 导出 Excel 横道图（色块按日/周）、任务表、日志；或导出 PNG

## 不会做什么

- 不是 Project / P6，不做资源均衡和挣值全套
- 横道按日历天，不自动扣节假日（可在任务里把工期改成日历天）
