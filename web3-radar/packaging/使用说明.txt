链上雷达 ChainRadar
====================

1. 请保持这个文件夹完整，不要只把 ChainRadar.exe 单独拷走。
2. 双击 ChainRadar.exe 启动（会弹出一个黑窗口，请不要关掉）。
3. 浏览器打开 http://127.0.0.1:8787

关于杀毒软件误报
----------------
本程序是研究用本地工具，不收集助记词/私钥，也不会偷偷联网安装别的软件。
Windows 有时会把「未购买代码签名」的 Python 打包程序误判成病毒。

如果仍被拦截：打开「Windows 安全中心 → 病毒和威胁防护 → 保护历史记录」，
把链上雷达标为「允许」；或把本文件夹加入排除项。

不要从网盘、聊天文件里运行来历不明的同名 exe。请只用 GitHub 发行版：
https://github.com/AAAAAAAA1231/DARC/releases/latest/download/ChainRadar.zip
