# 潜龙勇闯 Web3

魂斗罗式横版闯关：连射步枪、高低通道、飞行胶囊换枪、中段坦克和关底 Boss。

关卡：**ETH、ARB、ZK、STARK、L0、BASE**。

## 怎么玩

用浏览器打开 `index.html`，或：

```bash
python3 -m http.server 8765 --directory games/qianlong-web3
```

### 操作

| 键 | 作用 |
| --- | --- |
| `A` `D` | 跑 |
| `空格` / `K` | 跳，空中可再扇翼 |
| `W` | 朝上开火 |
| `S` | 蹲；滞空朝下打 |
| 按住 `J` / 鼠标 | 连射 |
| `P` / `Esc` | 暂停 |

打掉飞行胶囊换枪：**M 机枪 / S 散弹 / L 激光 / F 龙焰**。

独立演示，不影响 DARC 协议代码。
