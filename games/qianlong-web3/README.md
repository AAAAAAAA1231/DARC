# 潜龙勇闯 Web3

魂斗罗式横版射击小游戏原型：操控「潜龙战士」跑、跳、八向喷火，闯过 Web3 关卡。

关卡：**ETH、ARB、ZK、STARK、L0、BASE**。每关有地面敌军、炮台、飞行单位，以及关底 Boss。

## 怎么玩

用浏览器打开 `index.html`，或：

```bash
python3 -m http.server 8765 --directory games/qianlong-web3
```

访问 `http://localhost:8765`。

### 操作

| 键 | 作用 |
| --- | --- |
| `A` `D` / 左右 | 奔跑 |
| `空格` / `K` | 跳跃，空中可再扇一次翼 |
| `W` / 上 | 向上瞄准 |
| `S` / 下 | 蹲下；滞空时朝下开火 |
| `J` / `F` / 鼠标 | 喷火 |
| `P` / `Esc` | 暂停 |
| 触屏 | 左半屏移动，右下「跳 / 火」 |

打掉红色胶囊可换成 **散弹** 或 **ZK 激光**。通关解锁下一关（存在 `localStorage`）。

## 关卡特色

1. **ETH** — 教学，Boss 为 Gas 巨像
2. **ARB** — 移动平台 + Nitro 火力
3. **ZK** — 收集证明才能打开闸门
4. **STARK** — 间歇激光
5. **L0** — 跨链传送垫
6. **BASE** — 终章 Boss 战

独立演示，不影响 DARC 协议代码。
