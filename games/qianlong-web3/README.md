# 潜龙勇闯 Web3

一款以 Web3 公链 / L2 / 跨链协议为主题的浏览器小游戏原型。

驾驭「潜龙」闯过 **ETH、ARB、ZK、STARK、L0、BASE** 六关：喷火击毁 MEV 机器人与 Gas 墙，收集代币和零知识证明，穿过跨链虫洞。

## 怎么玩

直接用浏览器打开 `index.html`，或在本目录启动本地服务：

```bash
python3 -m http.server 8765
```

然后访问 `http://localhost:8765`。

### 操作

| 键 / 操作 | 作用 |
| --- | --- |
| `W A S D` 或方向键 | 移动潜龙 |
| 空格 / 鼠标左键 | 喷火 |
| `P` / `Esc` | 暂停 |
| 触屏 | 左侧拖动移动，右侧点按喷火 |

通关后会解锁下一关（进度存在浏览器 `localStorage`）。

## 关卡

1. **ETH · 创世主网** — 教学关，避开 Gas 墙
2. **ARB · Nitro 通道** — 加速滚动，Sequencer 脉冲
3. **ZK · 零知识电路** — 收集 SNARK 证明才能开启出口
4. **STARK · 多项式风暴** — 正弦激光与几何弹幕
5. **L0 · 跨链之桥** — 虫洞传送，跨链报文
6. **BASE · 链上盛夏** — 彩色终章

这是独立演示，不影响仓库中的 DARC 协议代码。
