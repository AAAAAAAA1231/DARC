# 工程成本（跟踪与纠偏）

本机成本工具。管目标成本、动态成本、已发生和待发生，看节超，写纠偏，导出 Excel。

## 用法（只下载、双击）

1. 下载压缩包：https://github.com/AAAAAAAA1231/DARC/raw/cursor/chengben-cost-f8d9/chengben/dist/ChengBen.zip
2. 右键 → 解压到当前文件夹
3. 双击 `ChengBen.exe`
4. 若弹出「Windows 已保护你的电脑」：点 **更多信息** → **仍要运行**
5. 浏览器打开 http://127.0.0.1:8795 ；不要关黑窗口

请下 zip，不要直接下 exe。数据在本机 `data/workspace.json`。

## 会做什么

- 目标 / 签证变更后的动态成本 / 已发生 / 待发生 / 预计总成本
- 节超金额和节超率：≥5% 预警，≥10% 超支
- 发生登记（进场、计量、结算）自动累加已发生
- 纠偏：量差/价差/签证漏项等，待落实 → 闭合
- 模板：住宅楼、市政道路、装饰装修
- 导出 Excel：成本台账、节超分析、纠偏、发生明细、签证、统计

金额单位为元，看板上的「万」只是换算。
