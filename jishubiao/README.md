# 工程技术标自动生成器

本机工具。填写工程概况、选择专业，按现行工程建设规范自动生成施工组织设计（技术标）初稿，导出 Word。

## 用法

双击 `dist/JiShuBiao.exe`，或在本目录执行：

```bash
pip install -r requirements.txt
python run.py
```

浏览器打开 http://127.0.0.1:8792

## 会做什么

- 按房屋建筑 / 钢结构厂房 / 装饰装修 / 市政道路 / 市政给排水 / 公路工程匹配规范
- 自动勾选 GB 55000 系列强制性通用规范及对应施工验收、安全标准
- 不写入已废止规范号（如 GB 50010-2002）
- 招标文件里出现 BIM、装配式、创优、智慧工地、海绵城市等关键词时，自动加专项章节
- 导出 `.docx` / Markdown

## 不会做什么

- 不复制规范全文（版权在出版社/标准发布机构）
- 不替代注册建造师、技术负责人审核
- 危大工程清单、机械台班、网络图仍需按施工图补全

生成稿须审核后再用于投标。
