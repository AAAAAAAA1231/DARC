# HCW 热搜雷达

每天双击一次，自动把「可能涨得多」的观察名单推到本地页面。

它实现的是前面说的 **HCW 三闸模型**：链外热搜 → 同名新盘 → 合约结构否决 → 市值窗口。**不是买卖建议，也不会自动下单。**

## 怎么用

1. 下载 `dist/HCWRadar.exe`
2. 双击打开（需联网）
3. 会自动弹出本地页面并开始扫描，大约 15–40 秒
4. 看这四栏：
   - **观察池**：今日热搜命中、结构没一票否决、市值还在发现/确认区
   - **已过窗口**：梗可能很强，但公开渠道已经定价（例如市值过三千万）
   - **链上异动**：没有链外热搜，更像上所 / KOL 催化盘
   - **结构否决**：蜜罐、高税、可增发、头部持仓 ≥ 40%
5. 看完点右上角「退出程序」

没有 Windows 时，可用 Linux 二进制：

```bash
./dist/HCWRadar
```

只出 JSON、不打开浏览器：

```bash
./dist/HCWRadar scan
```

## 它具体在干什么

打开后并行做这些事：

1. 拉微博 / 抖音 / 百度 / 头条 / 雪球热榜
2. 抽出短中文名和金融谐音词（牛、暴拉、哈基米……）
3. 用这些词搜 DexScreener，并拉取 BSC / Solana / Base 新池和热门池
4. 用 GoPlus 做蜜罐、税、增发、持仓集中度检查
5. 按 ATTN-7 打分，只保留观察价值最高的一类

发现边在第 1 步。新闻里已经出现的名字，模型会把它放进「已过窗口」，不会装成「下一个百倍」。

## 编译

```bash
cd hcw-scanner
bash build.sh
```

产物：

- `dist/HCWRadar.exe`  Windows 64 位，双击即用
- `dist/HCWRadar`      Linux 同款

## 数据源

| 用途 | 来源 |
|------|------|
| 热搜 | xxapi 微博热搜、NewsNow 微博/抖音/百度/头条/雪球 |
| 新盘 / 热门池 | GeckoTerminal |
| 关键词搜币 | DexScreener |
| 合约结构 | GoPlus |

全部是公开接口，不需要 API Key，也不连接钱包。

## 请务必记住

- 土狗当日死亡是常态，不是例外
- 市值不是池子里的真金，薄流动性下账面利润很难兑现
- 高分测的是「这个梗能不能涨」，不是「这个时点你还能不能赚」
- 本工具不能提高基础概率，只能帮你把大部分垃圾丢掉

中国大陆对虚拟货币相关业务有明确监管立场。请遵守所在地法律，不要把本程序当成荐币或代客理财工具。
