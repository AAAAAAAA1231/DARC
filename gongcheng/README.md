# 工程工作台

把清标、安全、进度、质量、成本、技术标收在一个本机软件里。双击后先进入首页，再点卡片进各模块。

## 用法（只下载、双击）

1. 下载压缩包：https://github.com/AAAAAAAA1231/DARC/raw/cursor/gc-suite-f8d9/gongcheng/dist/GongCheng.zip
2. 右键 → 解压到当前文件夹
3. 双击 `GongCheng.exe`
4. 若弹出「Windows 已保护你的电脑」：点 **更多信息** → **仍要运行**
5. 浏览器打开 http://127.0.0.1:8788 ；不要关黑窗口

请下 zip，不要直接下 exe。各模块数据在本机 `data/` 下分文件夹存放。

## 六个模块

- **清标**：经济标 / 技术标比对、图纸工程量
- **安全**：隐患台账、整改闭环
- **进度**：WBS、横道图、施工日志
- **质量**：问题台账、通病纠偏
- **成本**：目标/动态/已发生、节超纠偏
- **技术标**：按现行规范生成施工组织设计初稿
