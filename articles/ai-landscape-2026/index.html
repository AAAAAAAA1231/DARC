2026 AI 产品全景：特色、短板与适用建议

撰于 2026 年 8 月 28 日　面向普通用户、创作者、开发者与采购决策者　版本号每周都在变，选型逻辑比跑分更耐久

如果你还在问「现在哪个 AI 最强」，这个问题本身已经过时。2026 年夏天的格局很清楚：旗舰模型彼此咬得很紧，真正把人分开的，是产品形态、数据驻留、生态绑定、配额和你每天实际要做的那一类工作。ChatGPT 仍然最像瑞士军刀，Claude 仍然最像认真的写作者和工程师，Gemini 仍然最像长在 Google 里的操作系统，Grok 仍然最像盯着实时世界的观察哨。国内这边，豆包拿走了大众入口，DeepSeek 拿走了推理与性价比口碑，Kimi 拿走了长卷宗，通义千问拿走了开源与云上的中枢位置。

本文按「已知且仍在被广泛使用」的产品来写，不追求把每一个改名两周的实验室 demo 都塞进来，但会覆盖对话助手、搜索研究、编程、图像视频、语音音乐、办公企业、系统级 AI、开源私有化、以及正在成型的智能体。每一类先给总判断，再拆产品：特色、短板、适用建议。价格、上下文窗口、SWE-bench 分数会在三个月内过时；「它住在哪个生态里、它怕什么、你该不该把它当主力」不会那么快过时。

一、先立规矩：2026 年怎么看 AI 产品

过去两年，市场完成了三次换挡。第一次是「会不会聊天」；第二次是「上下文够不够长、会不会看图」；第三次，也就是现在，是「会不会调用工具、会不会进你的文件和业务系统、会不会在你离开屏幕时继续干活」。所以同一句「帮我写份方案」，在 ChatGPT、Claude、豆包、Copilot 里得到的，已经不是同一类东西：有的给你一段漂亮的散文，有的直接打开你的云盘，有的开始在浏览器里点来点去。

看产品时，建议固定问五个问题：

  • 它吃什么数据？公开网页、你上传的 PDF、你的邮箱日历、还是 X 上正在发生的帖子。
  • 它住在哪里？独立网站、IDE、Office、微信/抖音入口、手机系统，决定了你愿不愿意每天打开它。
  • 它敢不敢执行？只生成文本，还是能改文件、点网页、开 PR。
  • 它错了谁买单？个人娱乐可以幻觉；合同、代码、医疗、投资建议不行。
  • 免费层是不是诱饵？2026 年真正拉开差距的，往往是深度研究、智能体配额、百万级上下文和团队权限，都在付费层。

声明：下文对具体型号（如 GPT-5.6、Claude Opus / Fable、Gemini 3.x、Grok 4、Kimi K3、Qwen3.x、DeepSeek V4）的描述，以 2026 年 8 月公开报道与产品形态为准。实验室一周发一个版本号。请把本文当地图，不要当报价单。

二、四大通用助手

OpenAI全能主力

ChatGPT（GPT-5 系列 / 深度研究 / 语音 / 图像视频 / Agent）

特色。仍然是全球用户心智里的「默认 AI」。它的强不是某一个分项永远第一，而是产品面铺得最开：对话、画布式写作、代码解释器、联网、深度研究、自定义 GPT、Projects、高级语音、图像生成，以及从 Operator 收编进来的浏览器智能体。对很多非技术用户来说，一个订阅就能覆盖「问、写、画、搜、让它代点网页」。生态也最完整：API、企业版、教育版、第三方插件与 MCP 工具链都围着它转。

短板。旗舰推理模型更贵、更容易在长代理任务里把配额打光。独立评测多次指出：最强推理档在「奖励黑客」（为了看起来完成任务而走捷径）上并不干净，关键决策必须人工复核。图像/视频能力方便，但不一定是审美上限。对中国用户，访问、支付、数据出境和内容审核都是现实摩擦。它什么都有，所以也最容易让人误以为「一个就够」。

适用建议。个人把 ChatGPT Plus 当瑞士军刀，仍然划算。跨文本、语音、图像、浅层网页自动化的混合工作者，再考虑更高档。不要用它当唯一的代码仓库代理——那是 Cursor / Claude Code 的主场。不要用它当唯一的出处引擎——那是 Perplexity 的主场。

Anthropic写作 / 编程

Claude（Opus / Sonnet / Haiku，以及 Claude Code、Artifacts、Cowork）

特色。2026 年知识工作者里口碑最稳的一支。长文、方案、代码审查、结构化输出、诚实校准（它更愿意说「我不确定」）仍然是辨识度。Claude Code 把模型从聊天框拉进终端和仓库，Cursor、Windsurf 等编辑器也长期把它当作默认大脑之一。Artifacts 适合把回答变成可点的小工具或页面。对需要「读完再写、写完能用」的人，它经常比更吵的模型省时间。

短板。原生图像/视频生成不是它的产品重心，语音也不如 ChatGPT 完整。企业采购时，单独的 Anthropic 栈不如微软/谷歌好讲「我们本来就在用」。高档 Opus 贵，深度代理会话会迅速打穿 Pro 配额，这是 Claude Max 存在的原因。中文语感好，但国内落地、备案和本地办公套件整合弱于国产入口。

适用建议。写长文、改代码、做严肃分析：主力选 Claude。职业开发者优先买额度，而不是再开一个什么都沾一点的全能订阅。需要出图、出片、出语音时，把它的文字稿交给 ChatGPT、Midjourney 或 Veo，不要逼 Claude 变成多媒体工作室。

Google生态 / 超长上下文

Gemini（Gemini 3.x、Workspace、NotebookLM、Veo）

特色。最大的产品不是聊天网站，是「已经长在 Gmail、Docs、Drive、Meet、Search 里」。百万级甚至更高的上下文，让它吃年报、代码库切片、课程录像时很有体感。NotebookLM 把你自己的资料变成可追问的播客和笔记，是 2025–2026 年最被低估的学习产品之一。Veo 在带对白、口型和环境声的视频上，经常被拿来当质量标杆。免费档在海外长期被认为是「最能打的免费助手」。

短板。离开 Google 账号体系，它的魔力掉一半。企业里若邮件和文档在微软，Gemini 会变成又一个聊天窗口。有时回答偏「搜索摘要腔」，文学性和代码代理的黏手程度不如 Claude。Workspace 权限一旦配错，AI 能看到的范围会吓到安全团队——这是能力，也是事故源。

适用建议。生活和工作已经在 Google 里：Gemini 应是默认层，不必再为「再找一个通用聊天」付第二份钱。做个人知识库，先试 NotebookLM。做带台词的广告片，优先看 Veo。国内用户要先确认账号、网络与 Workspace 是否可用，再谈模型强弱。

xAI实时 / 社交语境

Grok

特色。它的护城河是 X（Twitter）上正在发生的事，以及更松的说话方式。热点、舆论、市场情绪、梗——这些对「昨天的网页快照」不友好的东西，Grok 更有现场感。对喜欢直给、讨厌客服腔的用户，它有情绪价值。编码跑分在 2026 年中段也曾冲到前列，说明它不再只是「马斯克的吐槽机器人」。

短板。企业治理、合规、审计、办公套件都不是主场。实时社交数据噪声极大，把帖子当事实会翻车。订阅常绑在 X 的层级上，对不用 X 的人是额外税。风格更冲，不适合直接粘进公文和对外 PR。

适用建议。做舆情、科技圈热点、需要「现在大家在吵什么」时打开。不要把它当知识库，不要当唯一写作引擎。和 Perplexity、专业数据库交叉验证后再用。

三、搜索、研究与带着出处的答案

通用助手都会联网，但「搜索原生」产品的信息架构不同：来源默认露出、引用可点、研究模式按小时跑、空间（Spaces）能把一组链接养成专题。聊天产品是「先说话再找补」；搜索产品是「先找再说话」。

Perplexity

特色。2026 年最干净的「答案引擎」。引用、Deep Research、专题空间、后续任务，都围绕「这件事现在怎么说、出处在哪」。对调研、竞品、选题、快速搞懂陌生领域，它比通用聊天少绕弯。Comet 等代理形态还在把「搜」推向「代你浏览」。

短板。长文气质和代码仓库能力不是它的灵魂。付费研究模式有配额。它依赖网页质量，遇上付费墙、公文非公开数据就哑火。有时过快下结论，需要你自己点开引用。

适用建议。当作浏览器主页式的研究入口。写论文、做行业简报：Perplexity 找材料，Claude 或 ChatGPT 成文。不要用它写小说，也不要用它替代内部知识库。

Google AI Overviews / AI Mode

特色。搜索框里直接出综述，流量最大，零学习成本。短板。早期幻觉伤过信任，复杂查询仍需点进源页。适用。日常事实、菜谱、营业时间；专业研究请升级到 Gemini Deep Research 或 Perplexity。

ChatGPT / Gemini / Kimi 的深度研究

特色。多步检索、长报告、能按你的提纲熬夜跑。短板。慢、吃配额、有时堆砌链接。适用。需要「像实习生交一版调研」而不是「三条蓝色链接」的时候。

NotebookLM

特色。只基于你喂的材料，幻觉面比开放联网小，能把资料变成对话和音频讲解。短板。材料质量决定上限，不是全网先知。适用。备课、读年报、消化自己的会议记录。

You.com、Exa、传统学术库 + AI

特色。更可配的检索、面向开发者的语义搜索、或 PubMed/CNKI 这类垂直库。短板。产品完整度不如头部。适用。有检索策略的人，而不是想「一个框搞定」的人。

四、中国超级入口与国产大模型

中国市场的逻辑和硅谷不完全一样。模型可以开源、可以极便宜，但胜负手往往是：中文语感、内容合规、能否连上钉钉/企微/飞书/微信、能否私有化、以及要不要翻墙。2026 年一个很健康的用法，是「豆包打日常，DeepSeek 打推理，Kimi 打长文档，通义打云和开源，再按公司栈补文心或星火」。

豆包（字节跳动，Seed 系列）

特色。国民级入口。对话自然、创作和轻办公顺手、多模态和短视频基因明显，和抖音/飞书体系靠近。对「我妈也能用」这件事，国内没有第二名。角色、写作、翻译、读图，足够覆盖 80% 生活场景。

短板。硬核推理、超长卷宗、严肃代码代理不是口碑最强项。企业要问清数据是否进公有云训练、能否专有化。功能多，深度用户会觉得有点「应用商店感」。

适用建议。大众默认下载。自媒体、轻办公、家庭问答从这里起步。需要数学证明、大规模重构、法律卷宗时，请换 DeepSeek / Kimi / Claude，不要在豆包里硬刚。

DeepSeek（深度求索）

特色。把全球 API 价格打下来的那一家。推理、数学、代码、开源权重，是技术圈真正买单的理由。网页端和 API 一体，适合当「脑子」而不是当「操作系统」。对开发者和学生，免费/低价体验仍然极有杀伤力。

短板。产品外壳相对克制，办公套件、语音、视频生成不是主菜。高峰期服务稳定性被吐槽过。视觉多模态中等。企业要单独评估部署、备案与供应链。

适用建议。程序员、研究生、要在自己产品里接模型的团队：先看 DeepSeek。不要指望它取代飞书文档里的那个按钮。它是发动机，不是整车。

通义千问（阿里，Qwen 系列 + 灵码）

特色。国内最完整的「模型 + 云 + 开源 + 应用」闭环。Qwen 开源家族在 Hugging Face 上的存在感极强，企业可以云上调用，也可以私有化。通义应用覆盖写作、读文档、多模态；通义灵码进 IDE。钉钉、阿里云客户有现成管道。

短板。C 端热闹程度通常不如豆包。产品线多，新人会迷路（千问、灵码、百炼、各种 Max/Plus）。最强闭源档与海外旗舰的差距要用场景测，不要只看发布会形容词。

适用建议。已经在阿里云/钉钉里的公司：优先通义，少造一轮数据出境审批。要开源可改、可本地部署：Qwen 几乎是默认候选。个人用户若更在意「好玩」，豆包仍更轻。

Kimi（月之暗面）

特色。长文本和处理资料的代名词：合同、论文包、网页合集、纪要。2026 年它明显往深度研究和 Agent 走，不再只是「能吃一百万字」。对咨询、法律辅助、学术阅读，体感仍然独特。

短板。曾经有过产品节奏被质疑「沉寂」的阶段，生态没有字节、阿里厚。纯闲聊和短视频创作不是它要赢的仗。付费档对重度长文用户才值。

适用建议。你的工作是「先读完再说话」：Kimi 应在收藏栏第一排。不要用它当唯一的画图和写代码工具。

文心一言 / 文心大模型（百度）

特色。中文写作、搜索增强、百度生态（搜索、网盘、如流）。全模态叙事在国内发布会上很激进。短板。开发者圈热度近年常被 DeepSeek/Qwen 盖过；产品品牌经历过多轮改名，心智有点散。适用。重度百度搜索/网盘用户、要中文公文和品牌文案的团队。

讯飞星火

特色。语音家底、教育、政务和行业知识库。听写、口语、课堂场景有真实渠道。短板。通用聊天的互联网声量不如豆包。适用。教育、会议转写、方言/语音输入密集的岗位。

智谱清言 / GLM

特色。GLM 开源+闭源双线，AutoGLM 一类浏览器辅助，学术和政企项目多见。短板。C 端入口不如巨头。适用。要国产模型、要私有化、又想要工具调用的团队。

MiniMax / 海螺、商汤日日新、腾讯元宝、百川、360 智脑

特色。海螺在视频生成 C 端很猛；腾讯元宝长在微信/QQ；商汤偏视觉与行业；百川、360 各有政企与安全叙事。短板。单点强、全家桶完整度参差。适用。跟着你已经在用的超入口走，不要为了「多一个模型」而多一个账号。

五、写代码的 AI：从补全到能改仓库

Cursor

特色。AI 原生 IDE 的代表。代码库索引、多文件编辑、Agent/Composer、多模型切换（Claude、GPT、Gemini、Grok 都能当大脑）。大仓库里「它记得项目约定」的体感，是普通 Copilot 补全比不了的。对已经用 VS Code 的人，迁移成本低。

短板。订阅贵，代理模式会烧掉大量额度。企业要审核代码是否出境。它再强也需要人看 diff——把 Agent 当成实习生，不要当成合并按钮。有时在混乱的遗留仓库里会自信地改错地方。

适用建议。个人开发者、创业团队、超过几万行的正经项目：优先 Cursor。公司已锁死 VS Code/JetBrains 插件白名单：改用 Copilot 或官方插件，不要为了编辑器打仗。

GitHub Copilot

特色。企业渗透率最高的编程 AI。VS Code、JetBrains、Neovim、甚至 Copilot 工作区，法律条款、IP 赔偿、SSO 是采购喜欢的词。2026 年它也开始接 Claude 等外部模型，等于微软承认「分发渠道」和「最强脑子」可以分开买。

短板。在大仓库代理、多文件重构上，口碑长期落后于 Cursor。坐在「还行的补全」舒适区太久，激进用户会流失。

适用建议。Fortune 级公司、要合规签字：Copilot 往往是唯一过得了法务的选项。个人若以速度为先，Cursor 或 Claude Code 更爽。

Claude Code

终端里的工程师。适合已经习惯命令行、要在真实仓库里长跑的人。配额是瓶颈，Max 档就是为此存在的。适用：深度重构、测试补齐、和 IDE 代理互补。

Windsurf、Trae、通义灵码、Amazon Q Developer、JetBrains AI、Tabnine

Windsurf 曾是 Cursor 的直接对手；Trae、灵码吃住国内开发者；Amazon Q 在 AWS 栈里有身份优势；JetBrains AI 给 IDEA 用户；Tabnine 偏私有化补全。适用：跟着你的 IDE 和云走，不要同时开五个代理。

Devin、Replit Agent、Bolt.new、Lovable、v0

Devin 想做「交 ticket 出 PR」的云端同事，贵，适合明确、可验收的后台任务。Replit / Bolt / Lovable / v0 擅长从提示词长出可演示的前端和内部工具，是产品经理的原型机，不是银行核心系统的施工队。

Sourcegraph Cody、Continue、Aider

更工程化、可自托管或可脚本化的路线。适合已经有代码搜索基础设施、或想把 AI 写进 CI 的团队。学习曲线高于「下载一个编辑器」。

六、图像、视频、声音：生成式媒体车间

图像：Midjourney、GPT 图像 / DALL·E、Flux、Stable Diffusion、Ideogram、Leonardo、Adobe Firefly、Recraft、Canva、即梦 / 可灵图像

特色。Midjourney 仍是「好看」的代名词，社区审美和氛围感领先；GPT 图像赢在「就在聊天里、文字能写进图」；Flux 和 SD 赢在可本地、可 API、可控；Ideogram 擅长海报字；Firefly 赢在 Adobe 套件和相对干净的训练数据叙事；Canva 赢在不会设计的人也能出图。国内即梦、可灵图像则吃住短视频封面和电商主图的本地审美。

短板。手、文字、品牌一致性、版权诉讼是全行业旧伤，只是严重程度不同。Midjourney 不是好 API 公民。开源线需要显卡和调参耐心。Firefly 有时被专业插画师嫌「太安全所以平」。

适用建议。概念和情绪板：Midjourney。聊天里随手出图：ChatGPT。要商用且法务敏感：Firefly 或明确授权的素材库。要批量、要流水线：Flux/SD + API。要图上有能读的中文大字：Ideogram 或国产海报模型，先试再押稿。

视频：Veo、可灵 Kling、Runway、Luma、Pika、海螺 Hailuo，以及仍在变动的 Sora

特色。Veo 常在「对白+口型+环境声」上被点名；可灵在运动、镜头和国内价格上很有竞争力；Runway 是创作者工具（时间线、运动笔刷、角色表演），不只是一次生成；Luma、Pika 适合快速试想法；海螺在国内 C 端声量高。OpenAI 的 Sora 在 2026 年产品形态多次报道不一：有的渠道说并入 ChatGPT 高档，有的说独立消费者产品收缩。选型时以你账号里实际还能点的按钮为准，不要以去年的发布会为准。

短板。时长、角色一致性、物理规律、审核、算力价格，全部没彻底解决。生成 4 秒很容易，生成可播出的 60 秒广告仍然要剪辑、补拍、人工修。水印和平台政策会改。

适用建议。带说话的广告：优先试 Veo。电影感运镜和国内工作流：可灵。要在工具里剪而不是只出片：Runway。个人玩梗：海螺/Pika/Luma。千万不要把「能生成」写成「能取代摄制组」交给客户。

声音与音乐：ElevenLabs、OpenAI 语音、讯飞、Suno、Udio

特色。ElevenLabs 是配音和克隆的工业级入口；ChatGPT 高级语音适合对话；讯飞适合中文听写与课堂；Suno/Udio 能从歌词长出带结构的歌。

短板。声纹滥用、版权、平台对 AI 音乐的下架政策。克隆别人的声音在多数司法管辖区是法律问题，不是技术问题。

适用建议。播客、有声书、产品演示配音可以上。未经授权的名人声音、员工声音不要碰。AI 音乐适合 demo 和内容配乐，不要默认能上发行商的核心歌单。

七、办公套件、笔记与企业平台

Microsoft 365 Copilot / Copilot Studio / Agent 365

Word、Excel、Outlook、Teams 里的那一层。特色是权限、审计、和已经付过钱的座位。短板是「不够惊艳」和席位费。适用：邮件和文档都在微软云的组织，几乎没有第二条路。

Google Workspace Gemini

同上，只不过战场在 Gmail/Docs。适用：Google 店。两套都上的公司会痛苦，请选一个当真相来源。

Notion AI、飞书智能伙伴、钉钉悟空、腾讯文档 AI

知识已经写在哪，AI 就应该出现在哪。Notion 对以 Wiki 为中枢的创业公司很顺；国内则跟飞书/钉钉/腾讯文档走。短板是检索质量和权限泄漏。适用：先治理文档，再开 AI，否则垃圾进垃圾出。

Gamma、美图/Canva 演示、Otter / Fireflies / 通义听悟

Gamma 适合快速幻灯片；会议转写工具适合「把说话变成待办」。短板是模板脸和错词。适用：内部分享可以；董事会材料仍需人改。

Salesforce Agentforce、ServiceNow、AWS Bedrock AgentCore、IBM watsonx、Palantir AIP

特色。2026 年企业 AI 的收敛点非常像：低代码智能体搭建、MCP 工具接入、策略网关、可观测性。Salesforce 吃 CRM，ServiceNow 吃 IT/HR 工单，Bedrock 吃「我要很多模型但不离开 AWS」，watsonx 吃强监管叙事，Palantir 吃数据融合与行动。

短板。贵、实施周期以季度计、demo 到生产之间有一条叫「主数据质量」的鸿沟。厂商功能表正在同质化，差异回到「你的数据已经在谁家」。

适用建议。按现有身份和数据湖选型，不要按发布会的智能体数量选型。没有治理的 Agent 平台，只是把幻觉接进了生产 API。

八、系统级 AI：苹果、微软、Meta、亚马逊

Apple Intelligence

特色是端侧+私有云、系统写作工具、通知摘要、和操作系统的深度耦合，隐私叙事是卖点。短板是能力上限通常低于云端旗舰，功能按地区语言滚动开放。适用：把手机当主力电脑的人，用来改邮件、摘要、修图，而不是写论文或重构代码。

Windows / 系统 Copilot

特色是键边栏、截图问、和 365 的连通。短板是产品身份长期在「搜索框、聊天、设置向导」之间摇摆。适用：已经在 Windows 企业镜像里的员工，把它当入口，把重活交给 365 或 ChatGPT。

Meta AI（Llama 生态 + 社交入口）

特色是 WhatsApp/Instagram/Facebook 里随手问，以及 Llama 开权重对整个工业界的供血。短板是助手体验常被觉得「泛」；Llama 许可证对部分地区/用途有限制。适用：社交场景里的轻助手；要本地部署时把 Llama 当底座之一，而不是当唯一信仰。

Amazon Q、Alexa+、Nova

特色是 AWS 开发者、客服和家庭音箱的续命。短板是消费级心智不如 ChatGPT。适用：订单、云资源、内部知识已经在 AWS 的团队。

还可以放进这一层的：Samsung 等手机厂商的端侧助手、汽车座舱语音、以及各家电视/耳机里的「AI 降噪和字幕」。它们很少赢在模型，赢在麦克风离你的嘴更近。

九、开源、开权重与能搬回家的模型

闭源助手解决「谁服务我」；开源解决「权重在谁硬盘上」。2026 年这条线已经不是爱好者玩具：Qwen、DeepSeek、Llama、Mistral、Gemma、GLM、Yi 等家族，配上 vLLM、Ollama、llama.cpp、Hugging Face、国内的硅基流动/Fireworks 类推理云，能撑起公司的内网助手。

特色。数据不出域、可微调、可审计、边际成本在自有 GPU 上可预测。Mistral 在欧洲采购里常被当成「主权答案」。Qwen/DeepSeek 让中文和代码本地化变得现实。

短板。运维、安全补丁、评测、红队，全部变成你的工作。开权重不等于可商用无限制，看许可证。效果上，小团队微调很少能稳定超过旗舰闭源 API，除非数据非常垂直。

适用建议。有合规红线、有 GPU、有平台组：上开源。只有三个程序员、没有人值夜班：买 API。混合才是成年人做法——边缘用开源，难题打到 Claude/GPT，中间用网关记账和脱敏。

周边工具值得单列：Hugging Face 是模型集市；Ollama 是个人电脑一键跑模型；OpenRouter 是「一个钥匙打很多模型」；LangGraph / Crew 类框架 是把智能体写成软件的脚手架。它们不是 C 端明星，却是 2026 年真实的工业底座。

十、智能体：能点鼠标的那一层

ChatGPT Agent（Operator 的继承者）

在远程浏览器里点、填、订。适合浅层网页流程，且有接管和确认。短板是登录态、验证码、反爬、支付风险。适用：已经付 ChatGPT 费、任务短、允许你盯着看的自动化。

Manus 等通用云端智能体

给一台云电脑，让它搜、写、编码、交成品（报告、站点、表格）。适合分析师式的长任务。短板是积分烧得快，失败时账单照走，安全边界要自己想清楚。适用：并行调研、可验收的交付物；不要把生产数据库密码交给它。

Claude Code / Cursor Agent / Devin

软件工程垂直智能体。适用：测试、样板、迁移、文档。短板：架构决策、安全补丁、不可逆操作。人必须看 diff。

各家「电脑使用 / 浏览器使用」：智谱 AutoGLM、国内电脑助手、RPA + LLM

把 UiPath 一类老 RPA 接上大模型，是企业里更土也更可能上线的路。纯视觉点鼠标在操作系统里仍脆。适用：字段稳定的后台；不要用于验证码对抗和灰产。

一套我愿意推荐给「认真用、但不当 AI 传教士」的人的组合：

十二、共同短板、风险与结语

把所有产品的短板叠在一起，其实是同一张清单：

  • 幻觉没有消失，只是被引用、被工具调用、被「我不确定」盖得好看了一点。涉及钱、健康、法律、生产配置，必须有人签字。
  • 评测榜与体感会打架。SWE-bench 第一的模型，不一定懂你的遗留系统；中文诗写得好的模型，不一定会改 Excel 数据透视。
  • 配额是隐藏产品税。智能体和深度研究按小时吞 token。200 美元档只对每天撞墙的人有意义。
  • 生态锁定是真的。你的邮件在哪，你的 AI 就应该先出现在哪。为了 3% 的跑分优势把工作流撕开，通常不值。
  • 版权、肖像、训练数据、生成内容水印，政策还在变。商用前问法务，不要问模型「你是不是没抄袭」。
  • 智能体有真实的误操作面。提示注入、错误点击、泄露 Cookie，比「写错一段话」更贵。停止按钮不是装饰。
  • 中国用户还有一层：访问、备案、内容审核、关键信息基础设施。能用和合法用，不是同一件事。
2026 年真正的素养，不是追每一个发布会，而是给自己的工作建一个小工具箱：一个主力、一个搜索、一个专业垂直，然后把其他的广告静音。

AI 产品会继续改名、涨价、合并、突然消失。Sora 可以收缩，某一个国内助手可以一个月换一个口号，这都不改变地图的画法：对话是入口，搜索是事实，编程工具是手，生成媒体是眼睛和耳朵，办公套件是权限，开源是主权，智能体是还没被驯服的腿。你不需要拥有整座城市。你只需要知道自己住在哪个街区，以及去别的街区该怎么走。

这篇图鉴有意写长，是为了对抗那种「一个排名解决人生」的短视频。若你读完只记住三句话，就够了：没有全能冠军；生态比跑分重要；人必须负责。
